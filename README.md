# 🌻 Sunny Valley Farm

A little farming game inspired by Harvest Moon. Dig the field, plant seeds, water them every day,
harvest your crops, sell them in the shipping bin, and take care of your chicken.

## How to play
Open `index.html` in a web browser.

- **Arrow keys / WASD**: walk
- **Space**: use your tool
- **1–4**: switch tools (hoe, watering can, seeds, hand)
- **Q**: change seeds

`simple-farm.html` is the first, simpler version of the game.
